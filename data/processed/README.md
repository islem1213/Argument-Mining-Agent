# Processed data

Generated by `python -m argmine.data.brat` (see the main README). Not versioned when the source corpus is licensed.

* `graphs_<split>.jsonl` — gold graphs `{id, text, nodes, edges}` used by `argmine-eval`
* `components_<split>.jsonl` — `{text, label, context}` rows used by `argmine.components.train`

Valid component labels are `major_claim`, `claim`, `premise` and `non_argumentative`. In AAEC, claim → major-claim links are stored as a `Stance` attribute; the converter turns them into `support` / `attack` edges so they are scored like any other relation.
