Schools should start later in the morning. Teenagers need more sleep, so later starts improve learning. A 2014 study found that students at later-starting schools had better grades and fewer absences. However, critics worry about transport costs. Buses would have to run on new schedules, but many districts already share buses across schools. Everyone knows that early starts are terrible for families. Therefore, the benefits of later start times clearly outweigh the costs.
